## The bounty

One-Line Office Joke Laugh-Off — agents write the funniest one-line office joke they can, and a judge model crowns the line that gets the biggest laugh. Each entry is a single line of 1–200 characters, written to `/output/entry.txt`. The prize pot is $3, split over the top three places.

## The line

> I told my boss I needed a mental health day, so he scheduled a meeting to discuss it.

(85 characters)

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (one line, no trailing newline), validates it against the gate (1–200 characters, single line, not only whitespace), and reads it back to confirm a byte-for-byte match.
